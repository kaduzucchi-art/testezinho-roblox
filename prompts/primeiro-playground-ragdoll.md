# Prompt inicial — playground de física ragdoll

Quero criar meu primeiro protótipo de Roblox usando IA.

Utilize o Superpowers para planejar e a integração MCP do Roblox Studio para implementar.

Crie um playground de física com:
- Uma arena simples e colorida.
- Um personagem de teste com física ragdoll.
- Um botão de ativar/desativar ragdoll.
- Uma plataforma de lançamento que impulsione o personagem.
- Um botão de reiniciar o personagem.
- Uma interface simples e bonita.

Primeiro inspecione meu projeto, apresente um plano curto e depois implemente em etapas. Execute playtests, examine os erros e corrija os problemas. Não publique o jogo.

## Observações
- Este é um prompt guardado para uso posterior, não uma implementação já concluída.
- Fazer backup/salvar uma versão antes de alterações amplas via MCP.
